# Anita's Tombrown

A simple static restaurant landing page for Anita's Tombrown, a Ghanaian Tom Brown brand serving comforting, homemade breakfast favorites.

## Overview

This project showcases a warm, modern marketing website for a small food business. It includes:

- A home page with hero section and menu highlights
- A contact page for customer inquiries
- An order page for placing an order
- Responsive styling for mobile and desktop layouts
- Light/dark theme support via JavaScript

## Project structure

- `index.html` — landing page
- `contact.html` — contact information page
- `order.html` — order form page
- `style.css` — site styling
- `script.js` — interactivity and theme toggle behavior
- `images/` — project assets and brand visuals

## Run locally

Because this is a static website, you can view it by opening `index.html` directly in a browser.

If you prefer a local web server, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
